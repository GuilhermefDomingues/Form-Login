# Modern Login Form

Projeto desenvolvido com HTML e CSS que apresenta uma interface moderna de autenticação. O formulário utiliza efeitos visuais em campos de entrada, labels flutuantes e elementos comuns encontrados em sistemas reais de login.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Campo de e-mail
- Campo de senha
- Labels animadas
- Opção "Lembrar-me"
- Recuperação de senha
- Link para cadastro
- Design moderno
- Responsivo

## 📂 Estrutura do Projeto

```bash
Modern-Login-Form/
│
├── index.html
├── css/
│   └── style.css
└── README.md
```

## 🎯 Como Executar

1. Clone ou baixe o projeto.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
